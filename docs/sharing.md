# 정적 화면 공유

GitHub Pages에는 `npm run build`로 생성한 `dist/`만 배포합니다. 계산과 이력 저장은 브라우저에서 실행하며 별도 API가 없습니다.

Node 서버로 정적 화면을 공유할 경우 `.env.shared.example`을 참고합니다.

| 환경변수                             | 의미                      |
| ------------------------------------ | ------------------------- |
| `PUBLIC_ORIGIN`                      | 경로 없는 HTTPS 공개 주소 |
| `HOST`                               | 공유 환경은 `0.0.0.0`     |
| `PORT`                               | 수신 포트. 기본 `4317`    |
| `ACCESS_USERNAME`, `ACCESS_PASSWORD` | 공유 화면 접속 계정       |

`npm start`로 실행하고 HTTPS 프록시가 원래 Host를 보존해 전달하도록 설정합니다. 기본 로컬 실행은 `127.0.0.1`에서만 수신합니다. 상태 확인은 `/healthz`입니다.

이력은 접속한 주소별 localStorage에 저장됩니다. 로그인 계정별 서버 보관·다른 기기 동기화 기능은 없습니다.
