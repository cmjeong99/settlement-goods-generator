      지원 범위와 사용 안내

      분석 범위

      조건부·다단계 계산은 ‘미확정’ 또는 ‘별도 계산 필요’로 표시해요. 전체 저장 프로시저의 실행 흐름은 분석하지 않아요. AI 검토로 미확정 값을 확정하지도 않아요.

      수식 분석·상품명 추천·복사는 브라우저에서 동작해요. 입력한 수식은 저장하거나 외부로 전송하지 않아요. AI 검토는 서버에서 별도로 제공해요.

      AI 연결 설정

      서버 폴더의 .env에 TypeSafe 공식 콘솔에서 발급한 JEV_API_KEY를 넣고 서버를 다시 시작하세요. 키는 브라우저로 보내지 않아요.

      SQL 입력은 100,000자, TypeSafe 요청은 UTF-8 32 MiB까지예요. 모델의 문맥 길이 제한에 걸리면 계산 구문을 나눠 주세요.

      입력 변경과 초기화

      SQL·컬럼명을 바꾸면 결과·AI 검토·상품명 선택을 초기화해요. 새로고침하면 입력과 결과가 사라져요.
